# Zapret · MD3 Configurator

Графическая оболочка для [zapret-discord-youtube от Flowseal](https://github.com/Flowseal/zapret-discord-youtube) на WPF / .NET 8. Она создаётся для людей, которым некомфортно работать с командной строкой: выбор стратегий и действия поставки должны выполняться через понятный интерфейс Material Design 3 Expressive.

Сейчас реализованы выбор поставки, проверка её исходных файлов, чтение состояния службы и редактирование пользовательских списков. Запуск стратегии, установка, остановка и удаление службы через GUI пока недоступны: для них ещё нужны проверки соответствия Flowseal, принадлежности установки и восстановления после ошибки. Совпадение хэшей исходников не объявляется совместимостью выполнения. План находится в [задачах оболочки](docs/tasks/flowseal-shell/README.md); замысел — в [документе продукта](docs/design/graphical-shell.md). Оформление представляет базовый MD3; Expressive остаётся отдельной задачей.

## Запуск

1. Распакуйте [Flowseal 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3).
2. Запустите `Zapret.Configurator.exe` и подтвердите UAC. EXE можно хранить отдельно от поставки.
3. Нажмите **Выбрать папку** и укажите распакованную папку с `service.bat`. Если поставка находится рядом с EXE, она обнаруживается автоматически.
4. Просмотрите заявленную версию, стратегии и готовность. Раскройте **Готовность компонентов и действий**, чтобы увидеть недостающие файлы, ограничения пути и причины недоступности действий.

Обнаружение рядом с EXE использует его каталог, а не рабочую папку терминала. Чтение принимает пути с пробелами; кириллица, OneDrive и специальные символы CMD сопровождаются объяснением ограничений выполнения. Проверка поставки не выполняет BAT, не запускает winws и не меняет службу, TCP или настройки. Ошибка чтения службы не скрывает готовность поставки. Состояние найденной службы ещё не подтверждает принадлежность выбранной поставке.

## Реализованные возможности

- Один заменяемый адаптер GUI описывает поставку и читает состояние службы.
- Поставленная версия проверяется по точным SHA-256 `service.bat` и всех 22 стратегий официальной 1.10.3. Версия, написанная в BAT, показывается отдельно.
- Изменённая или неизвестная стратегия остаётся видимой с объяснением. Другие исходные стратегии сохраняют свою проверку.
- Проверяется наличие компонентов `bin`, статических списков и управляющих файлов. Содержимое пользовательских списков, флагов и активных fake-файлов не фиксируется хэшами.
- Инструмент тестов имеет отдельную проверку и причину недоступности; его изменение не помечает стратегии как изменённые.
- Чтение статуса через `ServiceController` и имени активной стратегии из реестра; ошибка наблюдения обозначается состоянием «Неизвестно».
- Вкладка списков: поиск `list*.txt`, редактирование, добавление домена, IDN и защита от дубликатов. Редактирование доступно для исходного `service.bat` и имеющейся папки `lists`.
- Сохранение UTF-8 с сохранением BOM, резервной копией `.bak` и проверкой внешних изменений файла.
- Несохранённый список препятствует смене папки. После отмены или сохранения правок смена папки очищает редактор и загружает списки выбранной поставки.
- Светлая и тёмная темы, карточки MD3, Snackbar и асинхронные операции без консольных окон.

Сначала выберите список и нажмите **Открыть**. **Добавить** сразу сохраняет домен и текущие правки. Для перечитывания списка работающей стратегией используйте штатные действия Flowseal; GUI пока не выполняет её повторный запуск.

Происхождение эталона, карта исходных действий и форматы настроек зафиксированы в [контракте 1.10.3](docs/compatibility/flowseal-1.10.3.md). Дизайн описан в [документе MD3](docs/design/material-design-3.md). Значка в трее, фонового агента и автозапуска самого GUI нет.

## Сборка

Нужен .NET SDK 8 или новее с поддержкой целевой .NET 8 и Windows x64.

```powershell
dotnet restore src/Zapret.Gui/Zapret.Gui.csproj
dotnet build src/Zapret.Gui/Zapret.Gui.csproj -c Release --no-restore
dotnet publish src/Zapret.Gui/Zapret.Gui.csproj -c Release -o artifacts/publish
```

В `artifacts/publish` получается автономный единый EXE для Windows x64. Рантайм .NET включён; компоненты Flowseal берутся из выбранной распакованной поставки. Native-библиотеки рантайма извлекаются .NET автоматически при запуске.

## Проверки

```powershell
dotnet run --project tests/Zapret.Core.Tests/Zapret.Core.Tests.csproj
dotnet run --project tests/Zapret.Gui.Smoke/Zapret.Gui.Smoke.csproj -- artifacts/ui-light.png
dotnet run --project tests/Zapret.Gui.Smoke/Zapret.Gui.Smoke.csproj -- artifacts/ui-dark.png --dark --small
```

Core-проверки используют исходные файлы официального неизменяемого релиза и покрывают готовность, изменения исходников, пользовательские данные и ограничения пути. Сохраняются прежние проверки парсера BAT, кавычек, Game Filter, доменов и конфликтов записи. Успешный разбор BAT не доказывает соответствие исходному запуску; прежний парсер не используется для описания поставки.

WPF smoke проверяет границу GUI → адаптер, выбор папки, ошибку чтения службы, сохранность несохранённого списка и сброс редактора при смене поставки. Он загружает обе вкладки, проверяет bindings и контраст, рисует PNG и заменяет наблюдение Windows-службы. Для чтения полной локальной поставки можно передать Core `--inspect <папка>` или WPF smoke `--distribution=<папка>`. Ни одна из этих проверок не исполняет BAT и не меняет сеть или службы.

Проверки настоящих запусков и служб предстоят в выделенной тестовой Windows согласно [плану совместимости](docs/specs/flowseal-graphical-shell.md). Тесты, обновления, IPSet и диагностика остаются будущим графическим покрытием действий Flowseal.
