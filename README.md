# Zapret · MD3 Configurator

Графическая оболочка для [zapret-discord-youtube от Flowseal](https://github.com/Flowseal/zapret-discord-youtube) на WPF / .NET 8. Она создаётся для людей, которым некомфортно работать с командной строкой: выбор конфигураций и действия с поставкой Flowseal должны выполняться через понятный интерфейс Material Design 3 Expressive.

Стратегии и исходные действия берутся из поставки Flowseal. Целевой замысел описан в [документе продукта](docs/design/graphical-shell.md). Текущая версия покрывает установку службы и редактирование списков; она пока использует собственный разбор BAT и собственную регистрацию службы. Это частичная реализация замысла, соответствие которой Flowseal требует проверки. Текущее оформление представляет базовый MD3; работа над Expressive ещё предстоит.
Программа работает только пока открыто окно: значка в трее, фонового агента и автозапуска GUI нет.

## Запуск

1. Распакуйте [flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
2. Скопируйте `Zapret.Configurator.exe` в корневую папку рядом с `service.bat` и стратегиями `general*.bat`.
3. Запустите EXE и подтвердите UAC. Выберите стратегию и нажмите **Применить и запустить**.

Рабочая папка определяется по расположению EXE, а не по текущему каталогу терминала.
После успешного запуска GUI закрывается; переключатель позволяет оставить окно открытым.
Служба запускается автоматически при загрузке Windows независимо от GUI.

## Реализованные возможности

- Проверка состояния службы через `ServiceController`, чтение имени активной стратегии из реестра.
- Поиск BAT-пресетов в корне, разбор продолжений `^`, переменных `BIN`, `LISTS`, `%~dp0`, GameFilter и простых `set`.
- BAT-файлы не выполняются. Парсер отклоняет неизвестные переменные и несколько прямых запусков; проверка составных команд неполна, слитные BAT-операторы могут пройти предварительную проверку.
- Пути к спискам и BIN-файлам преобразуются в абсолютные; аргументы экранируются по правилам Windows.
- Перед регистрацией проверяются `bin/winws.exe` и файлы, используемые стратегией.
- Установка службы с автоматическим запуском, остановка процессов `winws`, удаление службы и остановка WinDivert.
- Вкладка списков: поиск `list*.txt` в подпапках, ручное редактирование, добавление домена, IDN и защита от дубликатов.
- Сохранение UTF-8 с сохранением BOM, резервной копией `.bak` и проверкой внешних изменений файла.
- Светлая и тёмная темы, карточки MD3, Snackbar и асинхронные операции без консольных окон.

Дизайн и соответствие компонентов спецификации описаны в [docs/design/material-design-3.md](docs/design/material-design-3.md).

Сначала выберите файл списка и нажмите **Открыть**. **Добавить** сразу сохраняет домен и текущие правки.
После изменения списка повторно примените стратегию, чтобы служба перечитала его.
При применении используются настройки существующего `utils/game_filter.enabled`; изменять игровой фильтр можно через `service.bat`.

## Сборка

Нужен .NET SDK 8 или 9 и Windows x64.

```powershell
dotnet restore src/Zapret.Gui/Zapret.Gui.csproj
dotnet build src/Zapret.Gui/Zapret.Gui.csproj -c Release --no-restore
dotnet publish src/Zapret.Gui/Zapret.Gui.csproj -c Release -o artifacts/publish
```

В `artifacts/publish` получается автономный единый EXE для Windows x64.
Рантайм .NET включён; `winws.exe`, WinDivert, стратегии и списки берутся из распакованной поставки flowseal.
Native-библиотеки рантайма извлекаются .NET автоматически при запуске.

## Проверки

```powershell
dotnet run --project tests/Zapret.Core.Tests/Zapret.Core.Tests.csproj
dotnet run --project tests/Zapret.Gui.Smoke/Zapret.Gui.Smoke.csproj -- artifacts/ui-light.png
dotnet run --project tests/Zapret.Gui.Smoke/Zapret.Gui.Smoke.csproj -- artifacts/ui-dark.png --dark
```

Core-проверки покрывают кавычки, BAT, GameFilter, домены, сохранение и конфликты записи.
Существующий набор проверок позволяет проверить разбор BAT, включая экранированный аргумент `^!` в FAKE TLS AUTO. Разбор текста не доказывает соответствие подготовки и результата штатному запуску Flowseal. Проверка исходников 16 октября 2026 года охватывала 22 локальные стратегии поставки 1.10.2; полный запуск тестов в этой среде не состоялся из-за отсутствия targeting pack .NET 8. Для проверки загруженных текстовых
пресетов: `dotnet run --project tests/Zapret.Core.Tests/Zapret.Core.Tests.csproj -- --upstream <папка>`.
WPF smoke-проверка загружает обе вкладки и рисует интерфейс в PNG без регистрации службы и без запуска winws.
Проверку установки и удаления настоящей службы выполняйте в тестовой Windows с распакованной поставкой flowseal:
применить → проверить Running и Automatic → закрыть GUI → убедиться, что служба работает → открыть GUI → удалить → проверить отсутствие службы и остановку драйвера.

Сейчас графически покрыты установка стратегии в автозапуск, удаление службы и редактирование доменных списков. Отдельный ручной запуск стратегии, изменение Game Filter, тесты, обновления и остальные действия `service.bat` пока не представлены в GUI. Набор функций первой версии и очередность расширения ещё не определены; отсутствие функции сейчас не является постоянным исключением из замысла оболочки.

Актуальный [пересмотр слабых мест](docs/audit-shell-2026-10-16.md) оценивает соответствие Flowseal, совместимость поставок и понятность для неподготовленного пользователя.
