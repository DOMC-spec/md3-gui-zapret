# Графическая оболочка для zapret от Flowseal

Приложение предоставляет понятный графический доступ к конфигурациям и действиям поставки zapret-discord-youtube от Flowseal. Оно предназначено для людей, которым некомфортно пользоваться командной строкой.

## Language

**Графическая оболочка**:
Приложение, через которое пользователь запускает конфигурации и выполняет действия поставки Flowseal в понятном графическом интерфейсе.
_Avoid_: самостоятельный zapret, движок обхода, отдельная система управления обходом

**Поставка Flowseal**:
Комплект zapret-discord-youtube от Flowseal, содержащий конфигурации, движок обхода, списки и служебные инструменты, с которыми работает оболочка.
_Avoid_: графическая оболочка

**Стратегия**:
Готовая конфигурация обхода из поставки Flowseal, которую пользователь выбирает для запуска.
_Avoid_: собственный алгоритм оболочки

**Ручной запуск стратегии**:
Запуск выбранной стратегии без установки её в автозапуск Windows.
_Avoid_: установка службы, автозапуск

**Автозапуск стратегии**:
Запуск выбранной стратегии при загрузке Windows посредством службы zapret.
_Avoid_: автозапуск оболочки

**Управляемая установка**:
Выбранная поставка Flowseal и относящиеся к ней служба и запущенные стратегии, принадлежность которых подтверждена оболочкой.
_Avoid_: любой zapret, любой winws

**Сторонняя установка**:
Установка или программа, не относящаяся к подтверждённой управляемой установке, в том числе использующая общий сетевой драйвер.

**Работа службы**:
Состояние запущенной службы zapret. Само по себе оно не означает доступность сервисов.
_Avoid_: интернет работает, обход работает

**Получение HTTP-ответа**:
Получение ответа от сетевой цели, включая ответы с ошибками. Само по себе оно не означает доступность нужной функции сервиса.
_Avoid_: сервис работает

**Доступность функции сервиса**:
Возможность выполнить конкретное пользовательское действие в сервисе, например воспроизвести видео или установить голосовое соединение.
_Avoid_: служба запущена, HTTP получен
