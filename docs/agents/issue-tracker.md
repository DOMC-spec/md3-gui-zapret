# Issue tracker: GitHub

Repository: MiffedFive/md3-gui-zapret
Issues: https://github.com/MiffedFive/md3-gui-zapret/issues

Задачи и спецификации хранятся в GitHub Issues.
Используй gh с явным --repo MiffedFive/md3-gui-zapret.

- Публикация задачи: gh issue create.
- Чтение задачи: gh issue view <number> --comments.
- Поиск задач: gh issue list.
- Метки: gh issue edit <number> --add-label / --remove-label.
- Закрытие: gh issue close <number>.
- Для многострочного текста используй --body-file.

PRs as a request surface: no.
