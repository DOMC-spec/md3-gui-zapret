# Triage labels

| Роль | Метка | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требуется первичная оценка |
| needs-info | needs-info | Ожидается дополнительная информация |
| ready-for-agent | ready-for-agent | Готово к реализации агентом |
| ready-for-human | ready-for-human | Требуется реализация человеком |
| wontfix | wontfix | Выполнять не планируется |

При упоминании роли используй соответствующую метку.
