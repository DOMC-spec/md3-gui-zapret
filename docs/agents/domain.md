# Domain docs

Проект использует один контекст.

Перед изучением кода прочитай GLOSSARY.md в корне и решения
из docs/adr/, относящиеся к текущей задаче.

Если этих документов нет, продолжай работу без дополнительных
действий. Создавай их через domain-modeling по мере появления
согласованных терминов и решений.

Используй термины из глоссария. Если предложение противоречит
существующему ADR, явно укажи решение и причину пересмотра.
