# Шаблон кейса стабильной приёмки

Скопировать для одного сценария; заполнить все поля до присвоения результата. Основание и границы — [паспорт](stable-acceptance-passport.md). Этот шаблон не является выполненным кейсом.

## Идентификация

| Поле | Значение |
| --- | --- |
| ID / GitHub Issue / название | Заполнить |
| Испытатель (имя или псевдоним), дата и часовой пояс | Заполнить |
| Версия оболочки, исходный коммит, тег, SHA-256 ZIP и EXE | Заполнить; новая сборка — отдельный результат |
| Flowseal: версия, коммит, официальный архив и SHA-256 | Заполнить |
| Windows: редакция, версия, сборка с UBR, x64, тип установки | Заполнить; CI не пользовательский стенд |
| Профиль А/Б; права процесса; UAC | Заполнить; разрешение владельца на системный прогон и проверенный возврат для Б |
| Каталоги EXE/поставки, cwd, тип/особенности пути | Заполнить; в публичной копии обезличить |
| Мониторы/разрешение/физический масштаб до и после переноса; размер окна | Заполнить; неизвестное не считать проверенным |
| Тема, уменьшение движения, способ ввода, reader и версия | Заполнить; для неприменимого поля указать причину |
| Предусловия и зависимости; ресурс стенда | Заполнить; не начинать при BLOCKED |
| Каталог обезличенных доказательств / манифест SHA-256 | `artifacts/stable-acceptance/<case-id>/<UTC-id>/` |

## Независимое исходное состояние

Для каждого поля указать значение, время, метод, ссылку на файл и успешность чтения. Различать ABSENT (объект отсутствует) и UNKNOWN (прочитать/доказать не удалось). Неприменимость требует причины и согласованного исключения, не PASS.

| Объект | До | Во время / после | Доказательство |
| --- | --- | --- | --- |
| SCM: состояние, полная конфигурация, ACL включая владельца/группу, тип запуска, зависимости, маркер | Заполнить | Заполнить | Независимые queryex/qc/sdshow и полный поддерживаемый снимок; одной DACL мало |
| Процесс: PID, фактический путь EXE, время создания, аргументы | Заполнить | Заполнить | Независимое чтение; имя и путь SCM не доказывают принадлежность |
| Драйвер: состояние, путь, тип запуска; сторонние потребители | Заполнить | Заполнить | Независимое чтение; не останавливать общий драйвер |
| TCP global, включая timestamps | Заполнить | Заполнить | Только чтение; не использовать status_zapret |
| Списки, настройки, флаги, используемые файлы | Состав, исходные байты локально, хэши | Создано/изменено/удалено, байты/хэши | Сохранить BOM/Unicode/пустые файлы; не публиковать личные данные |
| Незавершённая операция / защищённый журнал | Заполнить | Заполнить | Наличие, корректность и этап отдельно; отсутствие ключа не проверка восстановления |
| GUI | Заполнить | Заполнить | Скриншот/запись, текст результата и технических подробностей, доступные действия |

## Выполнение

1. Зафиксировать предусловия, исходное состояние и доступность возврата. Записать точные шаги и ожидаемый результат **до** запуска.
2. Выполнить описанный маршрут и записать фактический результат каждого шага с временем и ссылками. Терминал допустим для независимого наблюдения испытателем, не как обязательный шаг пользователя GUI.
3. При ошибке сохранить исходную ошибку, этап частичного эффекта, отдельный результат отката и следующий шаг GUI. Дефект оформить отдельно со ссылкой на воспроизведение; исправление требует повторного кейса на новом SHA-256.
4. Зафиксировать возврат: фактически выполненные шаги, работоспособность без GUI/сети для Б, независимое сравнение всех затронутых объектов. Внешние изменения не затирать, причину остановки записать.

| --- | --- | --- | --- | --- |
| Заполнить | Заполнить | Заполнить | Заполнить | Заполнить |

## Результат

- Статус: выбрать **PASS / FAIL / BLOCKED / NOT RUN**. PASS требует выполнения всех обязательных шагов, независимых доказательств и проверки возврата; доступность службы/HTTP и функция сервиса оцениваются отдельно.
- Причина и охват: заполнить. Для BLOCKED — точный ресурс/решение, ответственный и условие снятия; для NOT RUN — что ещё не запускалось.
- Возврат: выполнен / не требовался (почему) / заблокирован / ошибка; ссылки на сравнение до/после. Непроверенный план не результат возврата.
- Служба / HTTP-ответ / функция видео или голоса: отдельные наблюдения либо NOT RUN с причиной.
- Исключения: причина, согласовавший, дата, ссылка; не отмечать PASS.
- Дефекты и повтор: Issue, SHA-256 исправленного EXE, новый кейс; старое доказательство сохраняется.
- Подпись испытателя и дата; проверка обезличивания перед передачей.
