# v0.2.0-alpha.1 — оболочка Flowseal 1.10.3

**Предварительная альфа для ограниченного тестирования. Полная приёмка настоящих операций службы, драйвера и TCP не завершена. Это не стабильный и не полностью проверенный выпуск.**

## Возможности

- Выбор папки Flowseal и проверка исходных файлов всех 22 стратегий версии 1.10.3.
- Отдельные пробный запуск стратегии и автозапуск Windows; управление подтверждённой своей службой.
- Подготовка запуска, сохранение операции и восстановление при поддерживаемых условиях. Неподтверждённая принадлежность или неполный снимок блокируют изменение службы.
- Game Filter с отдельными TCP/UDP-диапазонами, сайты и исключения, резервные копии и защита от внешних правок.
- Наблюдаемое состояние отдельно от выбранной стратегии, понятные результаты действий, светлая/тёмная темы MD3 Expressive, видимый фокус и уменьшение движения.
- Исправлена гонка наблюдения Windows Job: завершение короткого вспомогательного процесса больше не выдаётся за отказ доступа к живому процессу. Выход подтверждается по дескриптору; недоступная идентичность живого процесса по-прежнему блокирует действие.

## Запуск

1. Скачайте ZIP оболочки и распакуйте его. Windows x64; .NET Runtime включён в EXE.
2. Отдельно скачайте официальную [Flowseal 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3). Она не включена в оболочку. SHA-256 архива Flowseal: `244314ae1c24538a0d751601da8e0c925c843371eec4456eb15f14c4fd6b7058`.
3. Распакуйте поставку в простой локальный ASCII-путь, например `C:\ZapretTest`. Существующую рабочую установку не перезаписывайте.
4. Запустите `Zapret.Configurator.exe`, подтвердите UAC и выберите папку с `service.bat`.
5. Проверьте версию, готовность и принадлежность службы. Если изменение запрещено, прочитайте причину; не обходите защиту ради тестирования.

При существующей службе из другой папки оболочка может показать конфликт или неподтверждённую принадлежность и запретить изменение. Это ожидаемая защита, а не предложение удалить рабочую установку. Автоматическая миграция Flowseal 1.9.6/1.10.2 и совместимость с ними не заявляются. Изменение службы и TCP может временно повлиять на сетевой доступ; сохраняйте рабочие настройки перед разрешёнными действиями.

## Что проверено

- Release-сборка, Core, полный Guard, сравнение аргументов всех 22 стратегий в двух режимах с исходным CMD-парсером и WPF smoke обеих тем. В Guard служба, TCP и системный журнал подменены; native fixtures инертны.
- Полный официальный архив 1.10.3: 21/21 Core-проверок, 22/22 исходных стратегий, наличие обязательных компонентов.
- Настоящий CMD helper Game Filter и сохранение списков на отдельной временной поставке.
- На рабочем компьютере: открытие предыдущего кандидата, ручной выбор поставки, чтение настоящей службы и безопасный отказ при неподтверждённом процессе. Состояния службы/драйвера/TCP и 38 файлов рабочей установки сохранились. После этого в наблюдение Windows Job внесено описанное выше исправление с отдельной нативной регрессией; полный UAC-маршрут новой сборки отдельно не подтверждён.

Результат CI и SHA-256 конкретных опубликованных файлов указываются в GitHub Release. Подробности: [проверка кандидата](https://github.com/MiffedFive/md3-gui-zapret/blob/v0.2.0-alpha.1/docs/tasks/flowseal-shell/12-verification.md), [ограниченная приёмка на рабочем компьютере](https://github.com/MiffedFive/md3-gui-zapret/blob/v0.2.0-alpha.1/docs/tasks/flowseal-shell/12-host-verification.md).

## Что остаётся непроверенным

Реальные установка/замена/запуск/остановка/удаление службы, пробный winws с настоящим драйвером, изменение TCP, защищённый журнал и аварийное восстановление не прошли полную нативную приёмку. Не выполнены 44 нативных сравнения из одинакового исходного состояния, полный ручной маршрут, конкретный screen reader и перенос между разными DPI.

Задача 12 и соответствующие пункты [выпускной матрицы](https://github.com/MiffedFive/md3-gui-zapret/blob/v0.2.0-alpha.1/docs/release/flowseal-1.10.3-acceptance.md) остаются открытыми. Отсутствие VM не заменено утверждением об успешной проверке. Работа службы и HTTP-ответ не доказывают воспроизведение видео или голосовое соединение.

Тесты Flowseal, обновления, IPSet и диагностика через GUI не реализованы и остаются следующим этапом.
