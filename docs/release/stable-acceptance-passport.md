Ни одно из этих решений не считается полученным по молчанию. #9 допускает завершение с перечисленными решениями и отсутствием Б; поддержка этим не расширяется.

## Возврат системы и сбор доказательств

Согласованный план допускает восстановимый образ системы или отдельную загрузочную установку на том же ПК либо среду добровольца. Конкретный способ возврата без GUI/сети **не выбран и не проверен**. Для #9 зарегистрировано отсутствие Б; согласование способа, доступность носителя/места/прав и фактический тест восстановления остаются решениями владельца. Копии списков, точка восстановления и журнал самого GUI не считаются полным откатом службы/драйвера/TCP. Системные действия до выполнения этих условий не начинаются.

Чтобы открыть Б, нужно записать носитель/образ и охват исходного состояния, способ офлайн-загрузки и восстановления без сети/GUI, исполнителя и окно работ; затем действительно восстановить контрольное состояние и независимо сравнить службу (включая конфигурацию/ACL/тип запуска/маркер), процесс, драйвер/потребителей, TCP и файлы. Только проверенный протокол и конкретное разрешение владельца открывают системные прогоны. На общем ПК они выполняются последовательно; обнаруженные внешние изменения не перезаписываются.

Формат каждого кейса — [шаблон](stable-acceptance-case-template.md). Оператор собирает независимые наблюдения до/во время/после; результат GUI хранится отдельно. Для профиля А возврат касается только выделенных временных файлов: исходные байты и итог сравниваются; рабочая установка не редактируется. PASS требует ссылок на доказательства; FAIL — наблюдаемого нарушения; BLOCKED — конкретного недостающего условия; NOT RUN — доступного, но ещё не выполненного сценария. Исключение отдельно согласуется и не становится PASS.

Локальное хранилище #9 — `artifacts/stable-acceptance-9/` (игнорируется Git): `issue-9.json`, `provenance.json`, `release.json`, `published.zip`, извлечённый `published/build.json`, независимые снимки и копии пользовательских файлов. Сборщик — Codex. Для будущих кейсов: `artifacts/stable-acceptance/<case-id>/<UTC-id>/`, оператор подписывает результат своим именем/псевдонимом и датой. В репозитории хранится обезличенный отчёт со ссылками/хэшами; исходные списки, персональные пути и посторонние журналы публично не загружаются. Перед передачей добровольцу проверить обезличивание. Локальные artifacts сами по себе недоступны удалённому читателю; передачу необходимых обезличенных доказательств обеспечивает оператор.
