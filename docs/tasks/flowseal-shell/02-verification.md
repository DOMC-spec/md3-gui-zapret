# Проверка задачи 02 — 17 октября 2026 года

Граница проверки — GUI → настоящий `FlowsealAdapter`. Заменены только наблюдение службы Windows и граница запуска команд; внутренние классы адаптера не подменяются. Реальные файлы исходных стратегий берутся из закреплённых fixtures 1.10.3; недостающие бинарные компоненты тестовой поставки создаются как инертный текст и никогда не запускаются.

## RED → GREEN

Вертикальные сценарии добавлялись последовательно: распознавание BAT-установки своей папки; отказ замены до восстановления; чужая/неизвестная принадлежность; неподдерживаемый и слитный BAT; недостающие файлы; внешнее вмешательство; недоступность остальных действий; неоднозначные пути, тип службы и текущий процесс; GUI с реальным адаптером. Каждый новый сценарий сначала давал ошибку компиляции отсутствующего публичного контракта либо наблюдаемый неверный результат, после чего добавлялась необходимая реализация. Межпроцессная проверка использует отдельный экземпляр только тестового EXE и две разные папки поставки.

## Проверенные результаты

- Guard: 12 групп public-сценариев; своя BAT-служба без GUI-маркера, чужая и неизвестная установка, неподдерживаемые/слитные команды, отсутствие обязательных и пользовательских файлов без их создания, неизменённая выбранная стратегия при правке другой, внешние изменения состояния/конфигурации/списка/стратегии/Game Filter/EXE, недоступные возможности, нормализация пути и его конечного разделителя, текущий процесс, межпроцессный mutex, отсутствие изменений всех файлов после отказа. Внешняя правка остаётся на месте, возвращённое состояние отражает вмешательство. Граница команд не вызывается.
- Core: 20 прежних проверок и дополнительная read-only проверка полной локальной поставки (21/0), включая атомарное сохранение, резервную копию и конфликт пользовательского списка.
- WPF smoke: настоящий адаптер и заменённое наблюдение ОС; принадлежность и причина отказа, сохранность списков/выбора папки, обе вкладки, bindings, контраст и раскладка. Светлая своя служба: `artifacts/task02-owned-light.png`; тёмная сторонняя служба при минимальном размере: `artifacts/task02-foreign-dark-small.png`.
- Release-сборка solution; версия выполнения и восстановление службы по-прежнему не заявлены.

Нативная read-only проверка выявила существующую работающую службу, для которой и QueryServiceConfigW, и штатный `sc.exe qc zapret` возвращали 1734. `sc.exe queryex` подтверждал Running. Сырой ImagePath содержит длинную конфигурацию Flowseal; добавлен ограниченный read-only fallback реестра для превышения лимита API. Адаптер сохранил наблюдаемое Running и сообщил неизвестную принадлежность, когда текущий процесс нельзя доказать. Существующая служба не изменялась. Команды `sc.exe` использовались отдельно исключительно для чтения при диагностике; автоматический guard-набор их не вызывает.

Это проверка отказов и чтения, а не Windows-интеграция изменения службы. Настоящие установки/замены/старты/остановки, восстановление, подготовка Flowseal и полный маршрут выпуска остаются задачами 03–12. Хэши исходных файлов сами по себе не доказывают совместимость выполнения.
