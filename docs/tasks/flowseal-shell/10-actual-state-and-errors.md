# 10: Актуальное состояние и понятный результат действий

**What to build:** Пользователь видит актуальный процесс, службу и стратегию, понятные ошибки и следующий шаг.

**Blocked by:** 05 — Понятное управление своей службой и автозапуском; 06 — Пробный ручной запуск исходной стратегии Flowseal.

**Status:** реализовано по прямому поручению пользователя 18 октября 2026 года; проверки и ограничения — [10-verification.md](10-verification.md). Реальная приёмка на выделенной Windows остаётся в задаче 12.

- [x] Раздельно отображаются выбранная стратегия, зарегистрированная стратегия автозапуска и подтверждённая работающая конфигурация; неизвестность не маскируется успехом.
- [x] При возврате в окно, после действий и перед изменением состояние перечитывается, в том числе после внешнего BAT.
- [x] Прогресс, причина ошибки, текущее состояние, результат восстановления и следующий шаг понятны без знания системных кодов.
- [x] Технические подробности доступны отдельно; Running не объявляется доступностью видео или голоса.
- [x] Проверены устаревший статус, отказ чтения, ранний выход, внешнее переключение и конфликт восстановления на согласованной границе GUI → адаптер и с подменами системных границ.
