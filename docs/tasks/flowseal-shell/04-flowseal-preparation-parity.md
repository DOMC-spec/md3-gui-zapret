# 04: Запуск службы с подготовкой и настройками Flowseal 1.10.3

**What to build:** Выбранная стратегия устанавливается с подготовкой и настройками, эквивалентными Flowseal 1.10.3.

**Blocked by:** 03 — Замена автозапуска с восстановлением при неудаче.

**Status:** реализация разрешена пользователем 17 октября 2026 года. Код и автоматические проверки выполнены в текущей ветке `codex/03-service-recovery-current`; реальная приёмка TCP и службы на выделенной Windows остаётся открытой вместе с приёмкой задачи 03.

Метод проверки, отличия адаптации и ограничения: [04-verification.md](04-verification.md).

- [x] Подготовка TCP timestamps, пользовательских списков и вычисление Game Filter сопоставлены с исходной 1.10.3; чтение статуса само не меняет TCP и не ожидает ввода.
- [x] Доступные штатные внешние вызовы возвращают значения в том же окружении либо явно экспортируют их; GUI не подменяет их независимой трактовкой 1.10.2.
- [x] Проверены mode, TCP/UDP-диапазоны, отсутствующий/пустой флаг, старые короткие значения, неизвестные режимы, дубликаты и неверные диапазоны по контракту 1.10.3.
- [x] Для всех 22 стратегий проверяется смысл аргументов и ссылок на файлы по исходному алгоритму установки с единым логическим корнем пути; подготовка проверена через адаптер. Ограничения нормализации пути описаны в отчёте.
- [x] Отказ подготовки не удаляет рабочую конфигурацию.
- [ ] Реальная проверка TCP, службы и штатной установки для всех 22 стратегий в выделенной Windows с восстановлением состояния.
