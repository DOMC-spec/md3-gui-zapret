# 04: Запуск службы с подготовкой и настройками Flowseal 1.10.3

**What to build:** Выбранная стратегия устанавливается с подготовкой и настройками, эквивалентными Flowseal 1.10.3.

**Blocked by:** 03 — Замена автозапуска с восстановлением при неудаче.

**Status:** draft — ожидает согласования; целевая метка после согласования: ready-for-agent.

- [ ] Подготовка TCP timestamps, пользовательских списков и вычисление Game Filter сопоставлены с локальной 1.10.3; чтение статуса само не меняет TCP и не ожидает ввода.
- [ ] Доступные штатные внешние вызовы возвращают значения в том же окружении либо явно экспортируют их; GUI не подменяет их независимой трактовкой 1.10.2.
- [ ] Проверены mode, TCP/UDP-диапазоны, отсутствующий/пустой флаг, старые короткие значения, неизвестные режимы, дубликаты и неверные диапазоны по контракту 1.10.3.
- [ ] Для всех 22 стратегий совпадают смысл аргументов, ссылки на файлы и подготовка со штатной установкой из одинакового состояния.
- [ ] Отказ подготовки не удаляет рабочую конфигурацию; реальная проверка TCP и службы проводится только в выделенной Windows с восстановлением состояния.
