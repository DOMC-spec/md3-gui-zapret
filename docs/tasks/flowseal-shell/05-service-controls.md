# 05: Понятное управление своей службой и автозапуском

**What to build:** Пользователь отдельно запускает/останавливает свою службу и удаляет автозапуск.

**Blocked by:** 03 — Замена автозапуска с восстановлением при неудаче.

**Status:** код и автоматические проверки реализованы по прямому поручению пользователя 17 октября 2026 года; приёмка на выделенной Windows остаётся открытой. См. [отчёт](05-verification.md).

- [x] GUI отдельно показывает включение автозапуска, запуск службы, остановку службы и удаление автозапуска; временная остановка не удаляет регистрацию.
- [x] Через адаптер подтверждается фактический переход состояния своей службы, в том числе установленной через BAT (автопроверки с моделью SCM; реальная Windows ниже).
- [x] Удаление ограничено своей службой; широкое удаление чужих процессов и служб не вызывается скрыто.
- [x] Тайм-аут, отсутствующая/остановленная служба и внешнее вмешательство имеют понятные результаты и проверки поведения.
- [x] Регистрация и управление не выдаются за полную совместимость подготовки, проверяемую задачей 04.
- [ ] На выделенной Windows проверены фактические Start/Stop/Delete, включая BAT-установку, тип автозапуска после остановки и сохранность сторонних потребителей WinDivert.
