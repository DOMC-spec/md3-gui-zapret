# 05: Понятное управление своей службой и автозапуском

**What to build:** Пользователь отдельно запускает/останавливает свою службу и удаляет автозапуск.

**Blocked by:** 03 — Замена автозапуска с восстановлением при неудаче.

**Status:** draft — ожидает согласования; целевая метка после согласования: ready-for-agent.

- [ ] GUI отдельно показывает включение автозапуска, запуск службы, остановку службы и удаление автозапуска; временная остановка не удаляет регистрацию.
- [ ] Через адаптер подтверждается фактический переход состояния своей службы, в том числе установленной через BAT.
- [ ] Удаление ограничено своей службой; широкое удаление чужих процессов и служб не вызывается скрыто.
- [ ] Тайм-аут, отсутствующая/остановленная служба и внешнее вмешательство имеют понятные результаты и проверки поведения.
- [ ] Регистрация и управление не выдаются за полную совместимость подготовки, проверяемую задачей 04.
