# 03: Замена автозапуска с восстановлением при неудаче

**What to build:** Неудачная замена стратегии автозапуска возвращает прежнюю конфигурацию и исходное состояние.

**Blocked by:** 02 — Отказ от опасного действия до изменения службы.

**Status:** реализация разрешена пользователем 17 октября 2026 года; код и автоматические проверки — в интеграционной ветке `codex/03-service-recovery-current`. Реальная приёмка изменения службы на выделенной Windows остаётся обязательной и не объявляется пройденной.

Исходное состояние, границы и проверки: [03-verification.md](03-verification.md).

- [x] Сохранить полный снимок поддерживаемой конфигурации и исходного состояния до замены; невозможность снимка оставляет службу нетронутой.
- [x] Ограниченный адаптер устанавливает проверенную конфигурацию без ввода цифр в консольное меню; успех подтверждается состоянием, аргументами, типом запуска и отсутствием раннего выхода.
- [x] Ошибки остановки, удаления, создания, запуска и ожидания возвращают прежнюю конфигурацию: работавшая служба работает, остановленная остаётся остановленной. Неудача самого восстановления сообщается отдельно.
- [x] При исходном отсутствии службы убирать только запись своей неудачной операции; обнаруженные сторонние изменения не перезаписывать.
- [x] Отдельно объяснять ошибку применения, результат восстановления и следующий шаг; отказные сценарии проверены через адаптер.
- [ ] Проверить реальные изменения и восстановление службы в выделенной Windows по [матрице приёмки](03-verification.md).
- [x] Полная совместимость подготовки не заявляется до задачи 04.
