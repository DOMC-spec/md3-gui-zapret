## Граница реализации

GUI вызывает единый `IFlowsealAdapter`. Предварительная проверка не изменяет службу. Выполнение повторяет проверку под общей блокировкой; подтверждает поддерживаемый снимок до остановки и проверяет внешние изменения перед дальнейшими действиями. Сбой применения, результат восстановления и следующий шаг передаются отдельно. Разрешение предварительной проверки сбрасывается при выборе другой стратегии и после выполнения.

Проверяется состояние службы, конфигурация, тип запуска и отсутствие раннего выхода. Работающая служба не является доказательством доступности видео или голоса. Полная подготовка Flowseal, семантика Game Filter, создание отсутствующих пользовательских списков и TCP timestamps остаются задачей 04; восстановление после аварийного завершения самого GUI — задачей 07.

Поддерживаемый снимок включает команду, тип службы/запуска, обработку ошибок, учётную запись, зависимости, отображаемое имя, описание, маркер стратегии, идентификатор операции и owner/group/DACL с защитой наследования. Допускается own-process под LocalSystem без группы загрузки и Tag; запрещены неизвестные дополнительные значения/подключи реестра, SACL, непереназначаемый текущим токеном owner/group, неполное наблюдение и сочетание Running с Disabled. Это ограниченный профиль восстановления, а не поддержка произвольной службы Windows.

Оба воспроизведены красными тестами и исправлены коммитом `ad2629d`: обнаруженный конфликт запрещает дальнейшее восстановление; собственное переходное состояние получает отдельное ограниченное ожидание. ## Проверка в выделенной Windows

Настоящая служба рабочего компьютера не изменялась. До подтверждения Windows-интеграции остаётся отдельная приёмка в одноразовой VM с полной распакованной Flowseal 1.10.3 и административными правами:

1. Исходно службы нет: установить стратегию через GUI; сверить ImagePath с ожидаемыми аргументами, Automatic, Running и сохранение Running после раннего наблюдения и закрытия GUI.
2. Установить прежнюю стратегию через BAT той же поставки. Сохранить конфигурацию и состояние; заменить через GUI; проверить принадлежность, новую стратегию и фактический процесс.
3. Повторить ошибки остановки, удаления, создания, запуска и ожидания через заменяемую системную границу адаптера с реальной Windows-службой. Сравнить конфигурацию до/после, описание, маркер стратегии и защиту службы. Для исходного Running проверить запуск прежней стратегии; для Stopped — отсутствие запуска.
4. Повторить сбой первого создания и запуска при исходном отсутствии; проверить отсутствие своей неудачной записи.
5. Между этапами изменить службу извне (другая папка, аргументы, состояние, маркер операции); убедиться, что дальнейшие изменения и восстановление прекращаются. Проверить конфликт второго экземпляра GUI во время выполнения и восстановления.
6. Проверить отказ до изменений для неподдерживаемых полей конфигурации и ошибки чтения снимка. Убедиться, что сторонние процессы и общий драйвер не останавливались.

Автоматические сценарии с инертными файлами не заменяют эту приёмку и не подтверждают совместимость выполнения Flowseal. Тестовый источник отказа не должен быть доступен как обычная настройка production GUI.
