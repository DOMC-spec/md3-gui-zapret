# 08: Графическая настройка Game Filter и диапазонов портов

**What to build:** Пользователь меняет Game Filter и диапазоны портов без консоли, сохраняя совместимость с BAT.

**Blocked by:** 04 — Запуск службы с подготовкой и настройками Flowseal 1.10.3.

**Status:** draft — ожидает согласования; целевая метка после согласования: ready-for-agent.

- [ ] Отображаются существующие настройки BAT; пользователь меняет штатные режимы и отдельные TCP/UDP-диапазоны без консоли.
- [ ] Ввод нормализуется и проверяется по контракту 1.10.3: границы портов, порядок диапазона, символы и пустые значения.
- [ ] Записывается штатный формат, затем результат перечитывается штатным механизмом Flowseal.
- [ ] Внешняя правка не теряется, пользовательский ввод сохраняется для разрешения конфликта.
- [ ] GUI различает сохранение и применение к процессу; матрица чтения/записи и пользовательский сценарий проверены через адаптер.
