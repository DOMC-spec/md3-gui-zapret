# 08: Графическая настройка Game Filter и диапазонов портов

**What to build:** Пользователь меняет Game Filter и диапазоны портов без консоли, сохраняя совместимость с BAT.

**Blocked by:** 04 — Запуск службы с подготовкой и настройками Flowseal 1.10.3.

**Status:** реализовано по прямому поручению пользователя 18 октября 2026 года; результаты — [отчёт](08-verification.md). Приёмка настоящего процесса и службы остаётся в задаче 12.

- [x] Отображаются существующие настройки BAT; пользователь меняет штатные режимы и отдельные TCP/UDP-диапазоны без консоли.
- [x] Ввод нормализуется и проверяется по контракту 1.10.3: границы портов, порядок диапазона, символы и пустые значения.
- [x] Записывается штатный формат, затем результат перечитывается штатным механизмом Flowseal.
- [x] Внешняя правка не теряется, пользовательский ввод сохраняется для разрешения конфликта.
- [x] GUI различает сохранение и применение к процессу; матрица чтения/записи и пользовательский сценарий проверены через адаптер.
