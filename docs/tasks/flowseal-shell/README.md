# План доработки оболочки Flowseal 1.10.3

Документы и задачи перенесены из локальной рабочей копии в ветку docs/flowseal-shell-plan форка DOMC-spec/md3-gui-zapret для последующего обсуждения с MiffedFive.

Задача 01 реализована по прямому поручению пользователя 16 октября 2026 года. Остальные задачи остаются черновиками; их реализация не выполнялась. Issues и Pull Request не создавались. Удалённая ветка не публиковалась в рамках переноса.

Основание — [спецификация](../../specs/flowseal-graphical-shell.md) и [замысел продукта](../../design/graphical-shell.md). Спецификация была подготовлена для 1.10.2; задачи уточняют целевую версию до локальной 1.10.3. Происхождение и точные исходные файлы 1.10.3 подтверждены в задаче 01; совместимость выполнения ещё предстоит подтвердить.

## Граница предложения

Цель — понятная графическая оболочка над поставкой Flowseal. Собственный движок обхода и универсальный BAT-интерпретатор не предлагаются. Подключение тестов, обновлений, IPSet и диагностики остаётся последующим этапом, не постоянным исключением.

Проверены локальные управляющие файлы 1.10.3: 22 стратегии, настройки Game Filter с отдельными TCP/UDP-диапазонами. Происхождение эталона закреплено официальным неизменяемым коммитом и хэшем релизного архива в [контракте 1.10.3](../../compatibility/flowseal-1.10.3.md); само совпадение с соседней локальной копией не было доказательством происхождения.

Перед реализацией остальных задач предлагается обсудить приоритеты, размер задач и зависимости. Автоматическое назначение задач приятелю не выполнялось.
