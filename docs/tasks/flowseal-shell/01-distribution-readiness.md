# 01: Выбор поставки и проверка готовности Flowseal 1.10.3

**What to build:** Пользователь выбирает поставку и видит её версию, стратегии и готовность без ручного переноса EXE.

**Blocked by:** None (can start immediately).

**Status:** complete — реализовано по прямому поручению пользователя 16 октября 2026 года; Issues и PR не создавались.

- [x] Выделить адаптер для описания поставки и чтения состояния внутри рабочего сценария GUI; не создавать отдельный общий рефакторинг.
- [x] Зафиксировать происхождение и хэши эталонных управляющих файлов 1.10.3 и 22 стратегий, карту действий и форматы настроек; пользовательские списки не считать управляющим кодом.
- [x] Папка с пробелами, обнаружение рядом с EXE, отсутствие компонентов и изменённая стратегия дают понятные результаты без исполнения BAT.
- [x] Совместимость не объявляется по одному номеру версии: возможности допускаются после проверок; согласованная граница GUI → адаптер покрыта тестами.

Реализация: GUI использует `IFlowsealAdapter` для описания выбранной поставки и чтения состояния. Папка выбирается штатным диалогом; по умолчанию проверяется каталог EXE. Подробности показывают отсутствующие компоненты, ограничения пути и возможности с причинами. Чтение службы может завершиться ошибкой независимо от готовности поставки. Несохранённые списки защищены при смене папки; чистый редактор сбрасывается.

[Эталон 1.10.3 и карта действий](../../compatibility/flowseal-1.10.3.md) привязаны к официальному коммиту и SHA-256 релизного архива; исходные fixtures содержат лицензию MIT и сохраняют точные байты. Пользовательские списки, флаги и активные fake-файлы не считаются управляющим кодом. Исходное редактирование списков сохранено с резервной копией и проверкой внешней правки. Запуск и управление службой заблокированы до последующих задач; совпадение исходников не заявляет полную совместимость.

Проверено: Core-контракт на исходных fixtures и полной соседней локальной поставке; WPF smoke через настоящий адаптер с подменой только наблюдения службы Windows, обе темы и обе вкладки; Release-сборка. Ни BAT, ни настоящие действия службы/сети при проверках не исполнялись. Полная матрица соответствия относится к задаче 12.
