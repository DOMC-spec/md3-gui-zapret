**What to build:** Пользователь выбирает поставку и видит её версию, стратегии и готовность без ручного переноса EXE.

**Blocked by:** None (can start immediately).

**Status:** draft — ожидает согласования; целевая метка после согласования: ready-for-agent.

- [ ] Выделить адаптер для описания поставки и чтения состояния внутри рабочего сценария GUI; не создавать отдельный общий рефакторинг.
- [ ] Зафиксировать происхождение и хэши эталонных управляющих файлов 1.10.3 и 22 стратегий, карту действий и форматы настроек; пользовательские списки не считать управляющим кодом.
- [ ] Папка с пробелами, обнаружение рядом с EXE, отсутствие компонентов и изменённая стратегия дают понятные результаты без исполнения BAT.
- [ ] Совместимость не объявляется по одному номеру версии: возможности допускаются после проверок; согласованная граница GUI → адаптер покрыта тестами.
