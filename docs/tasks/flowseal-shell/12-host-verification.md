# Задача 12: ограниченная приёмка на рабочем компьютере

Дата: 18 октября 2026 года. Пользователь отдельно разрешил доступные проверки на текущей системе вместо VM. Проверялись кандидат из `dd442a3` и документация `b301c73`; исходники приложения не менялись. Это дополнение к [проверке кандидата](12-verification.md), а не завершение выпускной матрицы.

## Исходное состояние

- Windows 11 Home x64, версия 10.0.26200. Команды проверки выполнялись с неповышенным Windows-токеном; разрешение исполнения вне sandbox не повышает UAC-токен.
- Служба `zapret`: Running, AutoStart, PID 30740, `C:\zapret\bin\winws.exe`; WinDivert Running, WinDivert14 отсутствует. TCP timestamps уже включены. Ключ `HKLM\SOFTWARE\ZapretGui.Recovery` отсутствует.
- В `C:\zapret\service.bat` заявлена версия **1.9.6**, обнаружены 19 стратегий; ни одна не совпадает с эталоном 1.10.3. Рабочая установка не заменялась.
- Архив `.scratch/flowseal-1.10.3.zip` проверен по SHA-256 `244314ae1c24538a0d751601da8e0c925c843371eec4456eb15f14c4fd6b7058`. Он распакован отдельно в ASCII-папку TEMP; поставка находится во вложенной папке `zapret-discord-youtube-1.10.3`.
- SHA-256 опубликованного EXE совпал с проверенным кандидатом: `4bdfdc5e354a2ddfeb5280faa022736b003070ecb3a05cb3853662e1f93ba381`.

Исходники обоих проверочных harness сохранены с локальными доказательствами, это не новые компоненты приложения.

## Сохранность рабочего компьютера

После прогона повторно сняты `sc queryex/qc zapret`, состояния WinDivert/WinDivert14, `netsh int tcp show global`, наличие recovery-ключа. Все шесть сравнений с исходным состоянием совпали, включая PID работающей службы. Дополнительно проверены SHA-256 и состав всех **38 файлов** `C:\zapret`: изменений/добавлений/удалений между снимками нет. Снимок файлов сделан перед настройками TEMP-поставки; предшествующие проверки рабочей папки выполняли только чтение.

Реальные Start/Stop/Delete/Install/ManualStart, изменение драйвера/TCP, запись защищённого журнала и аварийные сценарии не выполнялись: принадлежность процесса и пригодность снимка восстановления не подтверждены. Безопасные отказы не обходились. Восстановление не требовалось.
