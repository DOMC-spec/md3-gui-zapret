# 09: Добавление сайта и исключения с понятным назначением списка

**What to build:** Пользователь добавляет сайт или исключение и понимает, используется ли список выбранной стратегией.

**Blocked by:** 01 — Выбор поставки и проверка готовности Flowseal 1.10.3.

**Status:** draft — ожидает согласования; целевая метка после согласования: ready-for-agent.

- [ ] Пользователь видит понятные назначения списка и связь с выбранной стратегией; техническое имя и текстовый редактор доступны в расширенном режиме.
- [ ] Сохранены IDN, защита дубликатов, кодировка и резервная копия; отсутствующий пользовательский список создаётся штатно.
- [ ] Правка неиспользуемого списка не выдаётся за изменение активного обхода; указана необходимость повторного применения.
- [ ] При внешней правке или смене поставки пользовательские изменения не теряются: доступны перечитывание и сохранение своих правок отдельно.
- [ ] Проверен полный графический путь добавления сайта/исключения, включая конфликты и ошибки.
