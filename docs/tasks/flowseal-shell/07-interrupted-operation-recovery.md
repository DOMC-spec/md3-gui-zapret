# 07: Восстановление после аварийного закрытия оболочки

**What to build:** После аварийного закрытия пользователь видит незавершённую операцию и безопасный способ восстановления.

**Blocked by:** 03 — Замена автозапуска с восстановлением при неудаче; 06 — Пробный ручной запуск исходной стратегии Flowseal.

**Status:** реализация разрешена прямым поручением пользователя 18 октября 2026 года. Код и автоматические проверки; итог и открытая приёмка — в [отчёте](07-verification.md).

- [x] До изменения сохранять запись незавершённой операции и достаточное исходное состояние; успешное завершение закрывает запись.
- [x] После сбоя GUI читает реальное состояние через адаптер и объясняет незавершённую замену или пробный сеанс.
- [x] Восстановление не безусловное: чужие изменения и неизвестная принадлежность блокируют автоматическую перезапись.
- [x] Проверены аварийное завершение собственных тестовых процессов на этапах регистрации/пробного запуска, повторное открытие и повторное обращение к одной записи; служба моделируется.
- [x] Для восстановления не нужны фоновый агент и автозапуск GUI.
- [ ] Приёмка защищённого HKLM-журнала, реальной службы и аварий между внутренними шагами CreateService на выделенной Windows.
