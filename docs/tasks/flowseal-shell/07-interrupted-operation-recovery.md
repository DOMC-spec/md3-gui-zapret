# 07: Восстановление после аварийного закрытия оболочки

**What to build:** После аварийного закрытия пользователь видит незавершённую операцию и безопасный способ восстановления.

**Blocked by:** 03 — Замена автозапуска с восстановлением при неудаче; 06 — Пробный ручной запуск исходной стратегии Flowseal.

**Status:** draft — ожидает согласования; целевая метка после согласования: ready-for-agent.

- [ ] До изменения сохранять запись незавершённой операции и достаточное исходное состояние; успешное завершение закрывает запись.
- [ ] После сбоя GUI читает реальное состояние через адаптер и объясняет незавершённую замену или пробный сеанс.
- [ ] Восстановление не безусловное: чужие изменения и неизвестная принадлежность блокируют автоматическую перезапись.
- [ ] Проверены аварийное завершение на этапах регистрации/пробного запуска, повторное открытие и повторное обращение к одной записи.
- [ ] Для восстановления не нужны фоновый агент и автозапуск GUI.
