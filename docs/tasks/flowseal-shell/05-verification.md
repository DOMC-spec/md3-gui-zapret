17 октября 2026 года. Основание: `2741aa28aecbc417e80520244ab04fd68ba66ac3`, задача [05](05-service-controls.md), ADR 0001. Прямое поручение пользователя разрешило реализацию локальной задачи; GitHub Issue для неё не создавался.

## Поведение

GUI отдельно показывает тип запуска Windows, работу службы, включение автозапуска выбранной стратегии, запуск зарегистрированной службы, временную остановку и удаление автозапуска. Start/Stop/Remove не зависят от выбранного BAT и не закрывают окно после успеха. Доступность кнопок учитывает наблюдаемые принадлежность и устойчивое состояние, занятость GUI и возможности адаптера; разрешение замены после управления сбрасывается.

Адаптер повторяет наблюдение под общей блокировкой задачи 02. Start/Stop/Delete работают только с подтверждённой своей службой, в том числе установленной исходным BAT без маркера GUI. Полный снимок ACL для восстановления замены здесь не требуется: Start/Stop сохраняют регистрацию, Delete явно запрошен пользователем. Проверяются неизменность конфигурации, метаданных и файлов, переход SCM с пределом 10 секунд; после запуска — три дополнительных наблюдения через 400 мс с проверкой идентичности процесса. Нативная граница повторно сравнивает снимок перед командой Windows и использует дескриптор конкретной службы.

При удалении работающая своя служба сначала останавливается; до Delete выполняется новая проверка. Задержанное удаление Windows (1072) ожидается ограниченное время. Для отсутствующей службы Stop/Remove дают явный результат без команд, Start предлагает сначала установить автозапуск. Уже достигнутые Running/Stopped не вызывают повторной команды. Чужая, неизвестная и переходная служба не изменяется.

При ошибке или тайм-ауте показывается последнее прочитанное состояние и предложение обновить его. Операция Windows может продолжаться после тайм-аута. Частичные эффекты не маскируются автоматической переустановкой; внешние изменения сохраняются, следующие команды прекращаются. Широкий BAT remove, taskkill и управление общим WinDivert отсутствуют. Подготовка задачи 04 для этих действий не запускается; управление зарегистрированной службой не объявляется полной совместимостью Flowseal или доступностью видео/голоса.

## Независимый review

Два параллельных независимых агента проверили `2741aa2...4a62a96` по навыку code-review.

### Standards

Нарушений документированных правил нет. Сохранены ADR 0001, граница GUI → адаптер, повторные проверки принадлежности и прекращение действий при внешнем изменении. Один необязательный возможный smell: похожие циклы ожидания в `ServiceControls.cs` и `ServiceReplacement.cs`, включая обработку 1072 и проверку стабильности. Общий helper пока не выделялся: у controls другая проверка ошибок наблюдения, контроль файлов на каждом шаге и нет восстановления; объединение требует отдельного обоснования.

### Spec

Расхождений, некорректной реализации и расширения объёма задачи не обнаружено. Исходные пять пунктов покрыты кодом и автопроверками; приёмка настоящей Windows отдельно остаётся открытой. Частичные эффекты, внешние изменения после Stop, независимые команды GUI и BAT-установка покрыты содержательными сценариями.

Итого: Standards — 0 нарушений, 1 необязательное замечание о дублировании; Spec — 0 дефектов реализации, незавершённая нативная приёмка отмечена явно.
