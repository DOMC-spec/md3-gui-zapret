# Проверка задачи 12: кандидат выпуска 1.10.3

Задача 12 поручена 18 октября 2026 года. Базовый коммит: `c19a2100eed20c34fbeb0167198c919092598892`. Пользователь подтвердил отсутствие выделенной среды. Задача **не завершена целиком**: кандидат и обычные автоматические проверки не заменяют нативную выпускную приёмку зависимостей 03–07 и аппаратную доступность задачи 11.

## Изменения

- SDK закреплён в `global.json` на установленной 8.0.409; `Directory.Build.props` включает NuGet lock-файлы для всех пяти проектов. Сборка кандидата восстанавливает только в locked mode.
- `tools/Build-Candidate.ps1` требует чистый исходный коммит, выполняет Release build → Core → полный Guard → WPF light → WPF dark/small/200% → publish без пересборки. Все runner идут последовательно. ZIP создаётся только после успеха всех команд; отдельные папки запусков исключают упаковку устаревшего EXE после ошибки.
- Пакет включает EXE, README, лицензию, эталонный манифест Flowseal, выпускной протокол, build.json и SHA256SUMS. Журналы/PNG и SHA-256 архива сохраняются рядом. Статус пакета явно alpha-candidate.
- Обычный CI использует тот же скрипт на Windows 2022 с точным SDK, сохраняет также доказательства неудачного прогона. Удалённый CI ещё не запускался; push не выполняется этим поручением.
- [Матрица](../../release/flowseal-1.10.3-acceptance.md) содержит 22 стратегии × два режима Game Filter с незаполненной нативной приёмкой, области модельного покрытия, отдельный протокол VM из одинакового исходного снимка, сбор доказательств настоящего SCM/драйвера/TCP и аппаратной доступности. README обновлён под фактические возможности 01–11 и ограничения.

## Проверки

Первый restore под закреплённым SDK в sandbox остановился на записи sentinel в профиль .NET. Разрешённый повтор вне sandbox успешно восстановил solution и создал lock-файлы. Это ограничение окружения; оно не устанавливает причину прежних Access denied Guard.

Новые тесты на другой границе не добавлялись: здесь меняются сборка и документация. Используются существующие согласованные GUI → адаптер и системные seams. Прогон и независимый review описываются ниже после завершения.

## Остаток приёмки

Все семь критериев задачи 12 остаются открыты до окончательной оценки результатов. Происхождение эталона и описание нереализованных тестов/обновлений/IPSet/диагностики сохранены. Настоящие 44 сравнения стратегий, служба/драйвер/TCP, защищённый HKLM-журнал, полный маршрут на реальной поставке, физическая клавиатура, конкретный screen reader и смена мониторов с разным DPI не выполнялись. Видео и голос не сертифицированы. Работающие службы, драйвер, TCP и HKLM этого компьютера не изменяются ради этой задачи.
