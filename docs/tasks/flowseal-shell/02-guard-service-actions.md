# 02: Отказ от опасного действия до изменения службы

**What to build:** Пользователь получает отказ до изменения службы при чужой установке, неподдерживаемой стратегии или конфликте операций.

**Blocked by:** 01 — Выбор поставки и проверка готовности Flowseal 1.10.3.

**Status:** complete — реализовано по прямому поручению пользователя 17 октября 2026 года в локальной ветке task2; Issues, PR и публикация не выполнялись.

- [x] Проверять принадлежность службы по пути исполняемого файла, включая установку через BAT той же поставки; чужая или неопознанная установка остаётся нетронутой.
- [x] Не завершать все winws по имени и не останавливать общий драйвер при неизвестном стороннем использовании.
- [x] Блокировать параллельные изменения общей службы из разных GUI; обнаруженное внешнее вмешательство прекращает операцию.
- [x] Отказывать до изменений на неподдерживаемом BAT, слитных операторах и отсутствии обязательных файлов; проверки через адаптер доказывают отсутствие побочных действий.
- [x] До реализации полного восстановления из задачи 03 разрушительная замена недоступна с понятной причиной; чтение состояния остаётся доступным.

GUI вызывает публичные `ReadStateAsync`, `PreflightAsync` и `ExecuteAsync` настоящего адаптера. Принадлежность и причина недоступности показаны в карточке службы; отдельная кнопка повторяет предварительную проверку. Управление службой и прочие ещё не реализованные действия остаются недоступными. Прежние публичные `ZapretService.ApplyAsync`/`RemoveAsync`, завершение всех winws и остановка WinDivert удалены, поэтому обхода защиты через прежний API нет.

Общая служба защищается именованным `Global\Zapret.Flowseal.ServiceMutation.v1`, одинаковым для всех выбранных папок. Захват, повторное наблюдение и освобождение mutex выполняются на одном выделенном потоке; async-продолжение не переносит его владение. Сравниваются состояние, конфигурация службы, идентичность текущего процесса и содержимое/метаданные используемых файлов. Обнаруженная правка сохраняется; прерванный владелец блокировки даёт отказ. Неизменённые внешние BAT не участвуют в блокировке; защита от любого возможного изменения после последнего наблюдения не заявлена.

Принадлежность требует абсолютного, однозначного пути к обычному EXE без reparse-ссылок. Регистр и `..` нормализуются; неоднозначный некавыченный путь с пробелами, относительный путь, неизвестное окружение и неподдерживаемый тип службы дают неизвестную принадлежность. Раскрываются только фиксированные системные расположения `%SystemRoot%`, `%windir%`, `%SystemDrive%`; переменные окружения GUI не считаются окружением службы. Для работающей службы одной конфигурации следующего запуска недостаточно: также нужны путь и время создания процесса с PID из SCM.

Нативное чтение использует только QUERY_CONFIG/QUERY_STATUS, без прав изменения. API QueryServiceConfig ограничен 8 КиБ; если он даёт 122/1734 и измеренный ImagePath вместе с заголовком конфигурации не помещается в этот лимит, конфигурация читается из реестра без раскрытия окружения, с проверкой обязательных типов. Иначе принадлежность остаётся неизвестной. Снимок для полного восстановления задачи 03 этим не объявляется.

Проверки и ограничения зафиксированы в [отчёте проверки задачи 02](02-verification.md). Выполнение скриптов, изменение настоящей службы, сети, TCP, процессов winws или драйверов не проводились; совместимость выполнения относится к последующим задачам.
