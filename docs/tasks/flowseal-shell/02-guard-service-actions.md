# 02: Отказ от опасного действия до изменения службы

**What to build:** Пользователь получает отказ до изменения службы при чужой установке, неподдерживаемой стратегии или конфликте операций.

**Blocked by:** 01 — Выбор поставки и проверка готовности Flowseal 1.10.3.

**Status:** draft — ожидает согласования; целевая метка после согласования: ready-for-agent.

- [ ] Проверять принадлежность службы по пути исполняемого файла, включая установку через BAT той же поставки; чужая или неопознанная установка остаётся нетронутой.
- [ ] Не завершать все winws по имени и не останавливать общий драйвер при неизвестном стороннем использовании.
- [ ] Блокировать параллельные изменения общей службы из разных GUI; обнаруженное внешнее вмешательство прекращает операцию.
- [ ] Отказывать до изменений на неподдерживаемом BAT, слитных операторах и отсутствии обязательных файлов; проверки через адаптер доказывают отсутствие побочных действий.
- [ ] До реализации полного восстановления из задачи 03 разрушительная замена недоступна с понятной причиной; чтение состояния остаётся доступным.
