# 06: Пробный ручной запуск исходной стратегии Flowseal

**What to build:** Пользователь запускает исходную стратегию для проверки, наблюдает её и завершает пробный сеанс без включения автозапуска.

**Blocked by:** 04 — Запуск службы с подготовкой и настройками Flowseal 1.10.3; 05 — Понятное управление своей службой и автозапуском.

**Status:** draft — ожидает согласования; целевая метка после согласования: ready-for-agent.

- [ ] Запускается исходный BAT выбранной поддерживаемой стратегии из папки поставки; произвольный пользовательский текст не становится командой.
- [ ] Отделённый через start процесс winws наблюдается по пути, идентичности и времени создания; выход cmd не означает успех или завершение стратегии.
- [ ] Перед переходом со своей службы в пробный режим сохраняется её состояние и выполняется явная остановка; второй winws поверх службы не запускается.
- [ ] Остановка пробного сеанса и закрытие GUI завершают только свой процесс и возвращают исходное состояние без перезаписи сторонних изменений; последствия объяснены заранее.
- [ ] Долгоживущий процесс не ограничивается тайм-аутом короткой команды; ранний выход, отказ, пробелы и экранирование проверены.
- [ ] Интерактивная проверка обновлений подавляется штатным флагом окружения на время операции, с явным сообщением, что обновления не проверялись.
- [ ] Автозапуск не включается молча; соответствие реальному BAT проверяется в тестовой Windows.
