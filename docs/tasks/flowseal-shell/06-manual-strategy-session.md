# 06: Пробный ручной запуск исходной стратегии Flowseal

**What to build:** Пользователь запускает исходную стратегию для проверки, наблюдает её и завершает пробный сеанс без включения автозапуска.

**Blocked by:** 04 — Запуск службы с подготовкой и настройками Flowseal 1.10.3; 05 — Понятное управление своей службой и автозапуском.

**Status:** реализация разрешена прямым поручением пользователя 18 октября 2026 года. Код и автоматические проверки; результаты и оставшаяся приёмка — в [отчёте](06-verification.md).

- [x] Запускается исходный BAT выбранной поддерживаемой стратегии из папки поставки; произвольный пользовательский текст не становится командой.
- [x] Отделённый через start процесс winws наблюдается по пути, идентичности и времени создания; выход cmd не означает успех или завершение стратегии.
- [x] Перед переходом со своей службы в пробный режим сохраняется её состояние и выполняется явная остановка; второй winws поверх службы не запускается.
- [x] Остановка пробного сеанса и обычное закрытие GUI завершают только свой процесс и возвращают исходное состояние без перезаписи сторонних изменений; последствия объяснены заранее.
- [x] Долгоживущий процесс не ограничивается тайм-аутом короткой команды; ранний выход, отказ, пробелы и экранирование проверены с инертными процессами.
- [x] Интерактивная проверка обновлений подавляется штатным флагом окружения на время операции, с явным сообщением, что обновления не проверялись.
- [x] Автозапуск не включается молча.
- [ ] Приёмка исходного BAT с настоящим winws и драйвером на выделенной Windows; аварийное закрытие GUI — задача 07.
